# Cities

One file per ISO 3166-1 alpha-2 country: cities with 15 000+ inhabitants, largest first.
`n` name, `a` alternate Latin names, `y`/`x` latitude/longitude, `p` population.

Source: GeoNames cities15000 (https://www.geonames.org/), licensed CC BY 4.0. Rebuild with `node scripts/build-cities.mjs`.
